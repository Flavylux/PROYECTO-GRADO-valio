1. Sistemas de Numeración y Código Binario

En el frente técnico de esta unidad se estudia cómo la computadora representa información. Todo parte del sistema binario, donde cada bit adopta estado 0 o 1. 

                      SISTEMAS NUMERICOS
                               |
      +------------------------+------------------------+
      |                        |                        |
Sistema Decimal          Sistema Binario        Sistema Hexadecimal
 (Base 10: 0-9)           (Base 2: 0, 1)        (Base 16: 0-9, A-F)
Lenguaje Humano          Lenguaje Maquina          Direccionamiento

Sistemas posicionales fundamentales

  • Sistema Decimal (Base 10): utiliza diez símbolos (0-9) y cada posición representa potencias de 10.
  • Sistema Binario (Base 2): utiliza dos símbolos (0 y 1), base de toda representación digital.
  • Sistema Hexadecimal (Base 16): usa 0-9 y A-F para simplificar secuencias binarias largas.

Conversión y almacenamiento de datos

  • Binario a decimal: se multiplica cada bit por potencias de 2 según su posición y se suman los resultados.
  • Decimal a binario: se realizan divisiones sucesivas entre 2 y se leen residuos en orden inverso.
  • Unidades de memoria: bit, byte, KB, MB, GB y TB organizan la información en magnitudes crecientes.
  • Aplicación práctica: comprender estas conversiones facilita interpretar direcciones, archivos y codificación de datos.
Enfoque táctico: dominar numeración es la fase de preparación antes de diseñar algoritmos robustos.

2. Algoritmos y Diagramas de Flujo

Un algoritmo es una secuencia ordenada, finita y no ambigua de pasos para transformar entradas en salidas. En esta fase se consolida la lógica previa a la codificación.

Propiedades fundamentales de un algoritmo

  1. Precisión: cada instrucción debe ser clara y exacta.
  2. Finitud: todo algoritmo debe terminar en un número finito de pasos.
  3. Definición: con la misma entrada, debe producir la misma salida.
  4. Estructura: debe identificar entrada, proceso y salida.

Simbología esencial ANSI/ISO

  • Óvalo: marca inicio y fin.
  • Paralelogramo: representa entrada y salida de datos.
  • Rectángulo: indica proceso o cálculo.
  • Rombo: expresa decisión lógica (sí/no).
  • Flechas: definen el flujo de ejecución.
       [ INICIO ]
           |
           v
   / Leer valor de A /
           |
           v
   [ Resultado = A * 2 ]
           |
           v
      / ?A > 10? /
      /          \
  (Si) /          \ (No)
      v            v
 [ Imprimir X ] [ Imprimir Y ]
      \            /
       v          v
        ( FIN )
Escenario posguerra: tras el análisis inicial, el diagrama de flujo permite reconstruir el problema con orden y control.

3. Lógica y Metodología de Desarrollo

La metodología de desarrollo guía el proyecto en cuatro fases estratégicas: análisis, diseño, desarrollo y evaluación. Este ciclo mejora calidad, trazabilidad y mantenimiento. 

+---------------------------------------------------------------+
|                       1. ANALISIS                             |
|          Comprender el problema y determinar inputs/outputs   |
+---------------------------------------------------------------+
                               |
                               v
+---------------------------------------------------------------+
|                        2. DISENO                              |
|           Estructurar la solucion (Diagramas / Algoritmos)    |
+---------------------------------------------------------------+
                               |
                               v
+---------------------------------------------------------------+
|                      3. DESARROLLO                            |
|             Traduccion a codigo en un lenguaje                |
+---------------------------------------------------------------+
                               |
                               v
+---------------------------------------------------------------+
|                      4. EVALUACION                            |
|           Pruebas de software, depuracion y validacion        |
+---------------------------------------------------------------+

Fases del ciclo metodológico

  • Análisis: identificar necesidades, entradas, salidas y restricciones.
  • Diseño: modelar la solución con pseudocódigo, diagramas y reglas lógicas.
  • Desarrollo: implementar el diseño en un lenguaje de programación.
  • Evaluación: probar, verificar, validar y corregir errores.

Conceptos clave para no confundir

  • Hardware vs. software: físico tangible frente a lógica de instrucciones.
  • Compilado vs. interpretado: ejecución previa total frente a ejecución paso a paso.
  • Lógica vs. sintaxis: estrategia de solución frente a reglas gramaticales del lenguaje.

4. Principios de PSeInt para Diseñar Pseudocódigo

PSeInt es una herramienta educativa que permite entrenar razonamiento algorítmico en español antes de pasar a sintaxis formal como Python o C++.

1. Conceptos Básicos de PSeInt

Para programar en PSeInt necesitas entender cuatro pilares fundamentales:

  • Estructura del algoritmo: todo programa comienza con Algoritmo Nombre y termina con FinAlgoritmo.
  • Variables y tipos de datos: una variable es un contenedor para almacenar datos y debe declararse con Definir.
  • Salida de datos (Escribir): muestra texto o resultados en pantalla.
  • Entrada de datos (Leer): solicita un dato al usuario y lo guarda en una variable.
  • Asignación (<-): guarda un valor dentro de una variable.

Tipos de datos en PSeInt

  • Entero: números sin decimales (ejemplo: 10, -5).
  • Real: números con decimales (ejemplo: 3.1416, 18.5).
  • Cadena o Texto: texto entre comillas (ejemplo: "Hola Mundo").
  • Lógico: valores de verdad (Verdadero o Falso).

Fragmento de código: conceptos básicos

Algoritmo ConceptosBasicos
    // 1. Declaración de variables
    Definir nombre Como Cadena
    Definir edad Como Entero
    Definir estatura Como Real

    // 2. Salida y entrada de datos
    Escribir "Ingrese su nombre:"
    Leer nombre

    Escribir "Ingrese su edad:"
    Leer edad

    // 3. Asignación y operación
    estatura <- 1.75

    // 4. Mostrar resultados concatenando texto y variables
    Escribir "Hola ", nombre, ", tienes ", edad, " años y mides ", estatura, " metros."
FinAlgoritmo

2. Estructuras Condicionales (Toma de Decisiones)

Permiten que el programa tome diferentes caminos según se cumpla o no una condición lógica.

A. Condicional simple y compuesto (Si - Entonces - Sino)

  • Si - Entonces: ejecuta un bloque solo si la condición es verdadera.
  • Sino: ejecuta un bloque alternativo cuando la condición es falsa.
Algoritmo EjemploSiSino
    Definir edad Como Entero

    Escribir "Ingrese su edad:"
    Leer edad

    // Evaluación de la condición
    Si edad >= 18 Entonces
        Escribir "Eres mayor de edad. Puedes ingresar."
    Sino
        Escribir "Eres menor de edad. Acceso denegado."
    FinSi
FinAlgoritmo

B. Condicional anidado (Si dentro de otro Si)

Se utiliza para evaluar múltiples condiciones en secuencia. 

Algoritmo EjemploSiAnidado
    Definir nota Como Real

    Escribir "Ingrese su nota (0 a 10):"
    Leer nota

    Si nota >= 9 Entonces
        Escribir "Excelente"
    Sino
        // Se evalúa si no se cumplió la condición anterior
        Si nota >= 7 Entonces
            Escribir "Aprobado"
        Sino
            Escribir "Reprobado"
        FinSi
    FinSi
FinAlgoritmo

C. Condicional múltiple (Segun)

Es una alternativa más limpia a condicionales anidados cuando una variable puede tomar valores concretos, como en menús. 

Algoritmo EjemploSegun
    Definir opcion Como Entero

    Escribir "MENU DE OPCIONES:"
    Escribir "1. Saludar"
    Escribir "2. Despedirse"
    Escribir "Seleccione una opción (1-2):"
    Leer opcion

    Segun opcion Hacer
        1:
            Escribir "Hola. Bienvenido al programa."
        2:
            Escribir "Hasta luego. Que tengas un buen día."
        De Otro Modo:
            Escribir "Opción no válida."
    FinSegun
FinAlgoritmo

3. Estructuras Repetitivas (Ciclos o Bucles)

Los ciclos permiten repetir un bloque de código múltiples veces según una condición o un contador.

A. Ciclo Mientras (Pre-prueba)

Evalúa la condición antes de entrar al ciclo. Si no se cumple desde el inicio, el bloque nunca se ejecuta. 

Algoritmo EjemploMientras
    Definir contador Como Entero
    contador <- 1

    // Mientras el contador sea menor o igual a 5, repite el bloque
    Mientras contador <= 5 Hacer
        Escribir "Contador actual: ", contador
        contador <- contador + 1 // Incremento esencial para evitar bucles infinitos
    FinMientras
FinAlgoritmo

B. Ciclo Repetir (Pos-prueba)

Ejecuta el bloque al menos una vez y se detiene cuando la condición se vuelve verdadera. 

Algoritmo EjemploRepetir
    Definir clave Como Entero

    Repetir
        Escribir "Ingrese la clave de acceso (1234):"
        Leer clave

        Si clave <> 1234 Entonces
            Escribir "Clave incorrecta."
        FinSi
    Hasta Que clave = 1234 // Finaliza cuando esta condición sea Verdadera

    Escribir "Acceso concedido"
FinAlgoritmo

C. Ciclo Para (Determinado)

Se usa cuando se conoce con exactitud el número de iteraciones a realizar. 

Algoritmo EjemploPara
    Definir i Como Entero

    // Inicializa i en 1 y cuenta hasta 5 sumando de 1 en 1
    Para i <- 1 Hasta 5 Con Paso 1 Hacer
        Escribir "Iteración número ", i
    FinPara
FinAlgoritmo
