## Estructura Académica

### Unidad 1: Introducción al Mundo de la Programación

![Imagen Unidad 1](https://encrypted-tbn0.gstatic.com/images?q=tbn:ANd9GcQM6BPwLsPZtAFwagHXUU3m2fdZ86Q3UkHuhm64j_jlcg&s=10)

- Contexto histórico y pioneros de la computación.
- Evolución de las generaciones de computadoras.
- Avances tecnológicos e impacto en la sociedad.
- Sistemas operativos: conceptos, funciones y evolución.

### Unidad 2: Fundamentos de Lógica y Metodología de Desarrollo

![Imagen Unidad 2](https://codelearn.es/wp-content/uploads/sites/4/2022/09/binary-code.jpg)

- Sistemas de numeración: decimal, binario y hexadecimal.
- Conversión entre bases y representación de datos (bit, byte, KB, MB, GB, TB).
- Algoritmos y diagramas de flujo con simbología estándar.
- Metodología de desarrollo de software: análisis, diseño, desarrollo y evaluación.
- Diferenciación de conceptos clave: hardware/software, compilado/interpretado, lógica/sintaxis.
- Introducción a PSeInt y pseudocódigo.

### Unidad 3: Programación Estructurada y Lenguaje Python

![Imagen Unidad 3](https://encrypted-tbn0.gstatic.com/images?q=tbn:ANd9GcSrsQYmBv4uiQSy4G3PwImQJAclMJ-BIhDfOlaigbOsUQ&s=10)

- Lógica algorítmica aplicada con pseudocódigo y flujo estructurado.
- Fundamentos de Python y sintaxis básica.
- Estructuras condicionales con if.
- Estructuras repetitivas con while y for.

## Ejecución Local

Para ejecutar el proyecto localmente:

1. Abre una terminal en la carpeta del proyecto.
2. Ejecuta:

```bash
bash start.sh
```

3. Abre en el navegador la URL local mostrada por el servidor.
