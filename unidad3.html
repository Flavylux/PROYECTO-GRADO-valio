1. Diferenciación entre Diagrama de Flujo y DFD

Antes de programar, es clave distinguir dos herramientas que parecen similares pero cumplen funciones distintas.

¿Qué representa cada uno?

  • Diagrama de flujo: representa la secuencia lógica de acciones, decisiones y ciclos de un algoritmo.
  • DFD (Diagrama de Flujo de Datos): representa cómo la información entra, se transforma, se almacena y sale del sistema.
  • Enfoque clave: el diagrama de flujo describe control, el DFD describe datos.

Diferencia práctica

  • Si quieres saber qué se ejecuta primero, después y bajo qué condición: usa diagrama de flujo.
  • Si quieres saber de dónde vienen los datos y a dónde van: usa DFD.
  • En proyectos completos: ambos se complementan para diseñar soluciones más claras.
DIAGRAMA DE FLUJO (control)
Inicio -> Leer datos -> Procesar -> Decidir -> Mostrar resultado -> Fin

DFD (datos)
Usuario -> [Captura] -> (Proceso) -> [Base de Datos] -> Reporte

2. Pseudocódigo con PSeInt

El pseudocódigo expresa la solución en lenguaje humano estructurado. En PSeInt puedes probar esa lógica, detectar fallas y depurar antes de codificar en Python.

Principios prácticos en PSeInt

  • Secuencia: escribir pasos en orden lógico, de entrada a salida.
  • Selección: usar Si, Sino para decisiones.
  • Iteración: aplicar Mientras y Para en repeticiones.
  • Trazabilidad: verificar variables con prueba de escritorio antes de compilar.
  • Claridad: nombres de variables significativos e indentación consistente.

Ejemplo base en PSeInt

Algoritmo PromedioDosNotas
    Definir nota1, nota2, promedio Como Real

    Escribir "Ingrese la primera nota:"
    Leer nota1
    Escribir "Ingrese la segunda nota:"
    Leer nota2

    promedio <- (nota1 + nota2) / 2

    Si promedio >= 7 Entonces
        Escribir "Aprobado"
    SiNo
        Escribir "Reforzar contenidos"
    FinSi
FinAlgoritmo

3. Implementación Final en Python

Cuando la lógica ya está validada en diagramas y pseudocódigo, Python permite implementar el algoritmo con una sintaxis clara, moderna y orientada a la lectura.

1. Conceptos Básicos de Python

Python destaca por su sintaxis limpia: no requiere declarar tipos explícitos ni usar punto y coma al final de cada línea.

  • Variables y tipos de datos: se crean asignando valor directamente.
  • int: enteros (ejemplo: edad = 25).
  • float: decimales (ejemplo: estatura = 1.75).
  • str: cadenas (ejemplo: nombre = "Carlos").
  • bool: booleanos (True o False).
  • print(): salida de datos en consola; permite usar f-strings.
  • input(): entrada de datos; para números se convierte con int() o float().
  • Indentación: Python usa sangría de 4 espacios para delimitar bloques.

Fragmento de código

# 1. Entrada de datos y conversion de tipos
nombre = input("Ingrese su nombre: ")
edad = int(input("Ingrese su edad: "))
estatura = float(input("Ingrese su estatura en metros: "))

# 2. Asignacion directa y f-string para mostrar resultados
es_mayor = edad >= 18

print(f"Hola {nombre}, tienes {edad} anos, mides {estatura}m y eres mayor de edad: {es_mayor}")

2. Estructuras Condicionales (Toma de Decisiones)

Permiten ejecutar bloques de código según el cumplimiento de condiciones lógicas (True o False).

A. Condicional simple y compuesto (if - else)

  • if: se ejecuta si la condición es verdadera.
  • else: se ejecuta si la condición del if es falsa.
edad = int(input("Ingrese su edad: "))

# Evaluacion de la condicion
if edad >= 18:
    print("Eres mayor de edad. Puedes ingresar.")
else:
    print("Eres menor de edad. Acceso denegado.")

B. Condicional anidado y múltiple (if - elif - else)

En Python, en lugar de anidar muchos if o usar Segun, se utiliza elif para evaluar condiciones en secuencia. 

nota = float(input("Ingrese su nota (0.0 a 10.0): "))

if nota >= 9.0:
    print("Excelente")
elif nota >= 7.0:
    print("Aprobado")
elif nota >= 5.0:
    print("Recuperacion")
else:
    print("Reprobado")

C. Coincidencia de patrones (match - case)

Desde Python 3.10, match - case funciona como equivalente de Segun en PSeInt. 

opcion = int(input("MENU:\n1. Saludar\n2. Despedirse\nSeleccione una opcion: "))

match opcion:
    case 1:
        print("Hola. Bienvenido al programa.")
    case 2:
        print("Hasta luego. Que tengas un buen dia.")
    case _:
        print("Opcion no valida.")

3. Estructuras Repetitivas (Ciclos o Bucles)

Python utiliza principalmente dos ciclos: while y for.

A. Ciclo while (Mientras)

Evalúa una condición antes de cada iteración y se repite mientras sea verdadera. 

contador = 1

# Mientras la condicion sea verdadera, el ciclo continua
while contador <= 5:
    print(f"Contador actual: {contador}")
    contador += 1  # Equivalente a: contador = contador + 1
Nota: para simular Repetir...Hasta Que de PSeInt, se suele usar un bucle while True con break. 
while True:
    clave = int(input("Ingrese la clave (1234): "))
    if clave == 1234:
        print("Acceso concedido")
        break  # Sale del ciclo inmediatamente
    print("Clave incorrecta. Intente de nuevo.")

B. Ciclo for (Para)

En Python, for recorre secuencias. Para simular el Para clásico, se usa range(inicio, fin, paso). 

# Ejemplo 1: Recorrer un rango del 1 al 5
print("--- Conteo del 1 al 5 ---")
for i in range(1, 6):  # El limite superior (6) no se incluye
    print(f"Iteracion numero {i}")

# Ejemplo 2: Paso de 2 en 2
print("--- Numeros pares del 2 al 10 ---")
for i in range(2, 11, 2):
    print(i)
